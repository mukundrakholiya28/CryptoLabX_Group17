# CryptoLabX - Group 17

A comprehensive cryptography laboratory project exploring classical and modern cryptographic algorithms, attacks, and analysis.

## Project Structure

- **classical/** - Classical cryptography algorithms (Caesar, Vigenère, etc.)
- **attacks/** - Cryptographic attack implementations and analysis
- **math/** - Mathematical utilities and number theory functions
- **modern/** - Modern cryptographic algorithms (RSA, AES, ECC, etc.)
- **analysis/** - Cryptanalysis tools and frequency analysis
- **datasets/** - Test data and cryptographic datasets
- **outputs/** - Generated results and analysis outputs
- **docs/** - Documentation and references
- **tests/** - Unit and integration tests
- **utils/** - Utility functions and helpers

## Getting Started

1. Install dependencies: `pip install -r requirements.txt`
2. Run the main program: `python main.py`
